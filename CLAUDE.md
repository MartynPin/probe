# probe

Проект фабрики. Шаблон: `next-app`. Создан 2026-09-07.

## Прежде чем что-либо запускать

```bash
bash scripts/preflight.sh
```

Красный предполёт означает **сломанное окружение, а не твою ошибку**.
Не переписывай код под него: выполни то, что он предлагает, и запусти снова.

## Гейты

```bash
bash scripts/gates.sh
```

Коды выхода: `0` — зелено, `1` — красные гейты, `2` — `env_fail`,
`3` — все замечания вне твоей зоны.

## Зоны ответственности

| Зона | Пути | Кто пишет |
|---|---|---|
| Тесты | `tests/**` | только автор тестов |
| Продуктовый код | `app/**`, `lib/**`, `components/**` | только кодер |
| Схема и миграции | `prisma/**` | только кодер |

Если проблема лежит вне твоей зоны — не чини её и не молчи. Заверши работу и
напиши блок `## Вне моей зоны` с указанием пути и владельца.

## Конфигурация проверок

Менять разрешено, если это правильное решение. Требования: минимальная область,
объяснение комментарием в самом файле, блок `## Ослабление проверок` в ответе.
Без блока изменение блокируется гейтом.

## Схема

После правки `schema.prisma` клиент обязан быть перегенерирован **до** прогона
гейтов:

```bash
npx prisma migrate dev --name ИМЯ
```

Смена обязательности поля — такое же изменение схемы, как добавление модели.
