# Зона автора тестов

`tests/**` принадлежит роли «автор тестов». Кодер читает эти файлы, но не
правит их.

Тесты пишутся **до** кода и обязаны падать на пустой реализации. Падение на
утверждении, а не на импорте: тест, падающий только потому, что модуля ещё нет,
пройдёт после его появления, ничего не проверив.
